# Video decode: NVDEC (NVIDIA hardware decoder) against software

Measured 2026-10-09 01:39 UTC on Vihu (NVIDIA GeForce GTX 1650, 555.97; Intel64 Family 6 Model 165 Stepping 2, GenuineIntel), Windows-11-10.0.26200-SP0, by `bench/nvdec_decode.py` with ffmpeg version N-120812-g7caa2a65d9-20250821.
Decode only (FFmpeg to a null output: no detector, no OCR), 15 s per case after a 2 s start-up, two rounds in alternating order (software first, then hardware first). The simulator's other services ran as usual (publishers copying their clips into the relay, the API, the database); no analytics worker ran.

Clips: `GNR-POL-001.mp4` h264 1920x1080 at 25 fps, B-frames 0; `AMD-AMC-002.mp4` hevc 1920x1080 at 25 fps, B-frames 2.

Modes: **software** (CPU decode); **software-640** (CPU decode, each frame then resized to 640x360 on the CPU, the size class the detectors take); **nvdec-copy** (NVDEC decode, full frames copied back to system memory, what today's CPU-side worker would need); **nvdec-640** (NVDEC decode and the resize on the GPU, only the small frame copied back, as a GPU pipeline feeding a 640-px detector).
